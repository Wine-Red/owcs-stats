# 修复系统中存在的三个问题

## 问题1：数据管理页面中添加赛季-队伍-选手关联后显示"未知选手"

### 原因分析
- 在添加赛季-队伍-选手关联后，系统调用`loadSeasonTeamPlayers()`重新加载关联数据
- 但此方法只更新了`store.state.seasonTeamPlayers`，未更新`store.state.players`
- 当选手是新添加时，`store.state.players`中无该选手信息，导致`getPlayerName()`返回"未知选手"

### 解决方案
- 修改`DataManage.vue`中的`saveEdit`方法，在添加赛季-队伍-选手关联后重新加载所有选手数据
- 确保`store.state.players`包含最新的选手信息

## 问题2：数据录入页面中选择赛季后队伍选项不显示

### 原因分析
- 在`DataEntry.vue`中，选择赛季后会调用`store.dispatch('getSeasonTeams', newSeasonId)`加载赛季队伍
- 但`computed`的`seasonTeams`使用`store.getters.getTeamsBySeasonId`获取队伍
- 可能存在数据更新时机问题，导致队伍选项未及时显示

### 解决方案
- 检查并优化`getTeamsBySeasonId` getter实现
- 确保赛季选择后队伍数据能正确加载并显示

## 问题3：地图局时长调整后仍提示"时长必须大于0"

### 原因分析
- 地图局时长验证规则设置为`{ min: 1, message: '时长必须大于0', trigger: 'change' }`
- 但`addMapGame()`方法中新创建的地图局对象`duration`初始值为0
- 可能存在数据类型或验证触发时机问题

### 解决方案
- 修改`DataEntry.vue`中地图局时长的验证规则
- 确保时长调整为大于0后能正确通过验证

## 修复步骤

1. **修复问题1**：修改`DataManage.vue`中的`saveEdit`方法，在添加赛季-队伍-选手关联后重新加载选手数据

2. **修复问题2**：检查并优化`store/index.js`中的`getTeamsBySeasonId` getter实现

3. **修复问题3**：修改`DataEntry.vue`中地图局时长的验证规则和初始值设置

4. **测试验证**：确保三个问题都已修复，系统能正常运行
