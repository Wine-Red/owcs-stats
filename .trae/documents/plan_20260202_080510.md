# 数据库结构设计 - 支持一个队伍参加多个赛季

## 核心表结构

### 1. seasons (赛季表) - 手动维护

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **name** (VARCHAR(100), NOT NULL, UNIQUE) - 赛季名称

* **status** (ENUM('in\_progress', 'completed'), NOT NULL, DEFAULT 'in\_progress') - 赛季状态

### 2. teams (队伍表) - 手动维护

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **name** (VARCHAR(100), NOT NULL, UNIQUE) - 队伍名称

* **region** (VARCHAR(50), NOT NULL) - 所属地区

### 3. players (选手表) - 手动维护

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **name** (VARCHAR(100), NOT NULL) - 选手游戏ID

* **role** (ENUM('tank', 'damage', 'support'), NOT NULL) - 职责

### 4. maps (地图表) - 手动维护

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **name** (VARCHAR(100), NOT NULL, UNIQUE) - 地图名称

* **type** (ENUM('推进', '护送', '控制', '混合', '闪点'), NOT NULL) - 地图类型

### 5. heroes (英雄表) - 手动维护

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **name** (VARCHAR(100), NOT NULL, UNIQUE) - 英雄名称

* **role** (ENUM('tank', 'damage', 'support'), NOT NULL) - 英雄职责

### 6. season\_teams (赛季-队伍关联表) - 支持一个队伍参加多个赛季

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **seasonId** (INT, NOT NULL, FOREIGN KEY REFERENCES seasons(id)) - 赛季ID

* **teamId** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 队伍ID

* **UNIQUE KEY** (seasonId, teamId) - 确保每个队伍在每个赛季只出现一次

### 7. season\_team\_players (赛季-队伍-选手关联表) - 表达"这个赛季这支队伍的选手名单"

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **seasonId** (INT, NOT NULL, FOREIGN KEY REFERENCES seasons(id)) - 赛季ID

* **teamId** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 队伍ID

* **playerId** (INT, NOT NULL, FOREIGN KEY REFERENCES players(id)) - 选手ID

* **UNIQUE KEY** (seasonId, playerId) - 确保每个选手在每个赛季只属于一个队伍

* **UNIQUE KEY** (seasonId, teamId, playerId) - 确保每个选手在每个赛季每个队伍只出现一次

### 8. matches (比赛表) - 前端录入

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **seasonId** (INT, NOT NULL, FOREIGN KEY REFERENCES seasons(id)) - 赛季ID

* **team1Id** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 队伍1 ID

* **team2Id** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 队伍2 ID

* **winnerId** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 获胜队伍 ID

* **matchDate** (DATE, NOT NULL) - 比赛日期

* **UNIQUE KEY** (seasonId, team1Id, team2Id, matchDate) - 确保比赛不重复

### 9. map\_games (地图局表) - 前端录入

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **matchId** (INT, NOT NULL, FOREIGN KEY REFERENCES matches(id)) - 比赛 ID

* **mapId** (INT, NOT NULL, FOREIGN KEY REFERENCES maps(id)) - 地图 ID

* **winnerId** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 获胜队伍 ID

* **duration** (INT, NOT NULL) - 地图局时长（分钟）

* **team1BanHeroId** (INT, NULL, FOREIGN KEY REFERENCES heroes(id)) - 队伍1 ban的英雄

* **team2BanHeroId** (INT, NULL, FOREIGN KEY REFERENCES heroes(id)) - 队伍2 ban的英雄

### 10. player\_stats (选手数据表)

* **id** (INT, PRIMARY KEY, AUTO\_INCREMENT)

* **mapGameId** (INT, NOT NULL, FOREIGN KEY REFERENCES map\_games(id)) - 地图局 ID

* **playerId** (INT, NOT NULL, FOREIGN KEY REFERENCES players(id)) - 选手 ID

* **teamId** (INT, NOT NULL, FOREIGN KEY REFERENCES teams(id)) - 队伍 ID

* **heroId** (INT, NOT NULL, FOREIGN KEY REFERENCES heroes(id)) - 使用的英雄 ID

* **kills** (INT, NOT NULL, DEFAULT 0) - 击杀数

* **deaths** (INT, NOT NULL, DEFAULT 0) - 死亡数

* **assists** (INT, NOT NULL, DEFAULT 0) - 助攻数

* **damage** (INT, NOT NULL, DEFAULT 0) - 伤害量

* **healing** (INT, NOT NULL, DEFAULT 0) - 治疗量

* **mitigation** (INT, NOT NULL, DEFAULT 0) - 伤害减免量

* **ultsUsed** (INT, NOT NULL, DEFAULT 0) - 大招使用次数

* **finalBlows** (INT, NOT NULL, DEFAULT 0) - 最后一击数

* **UNIQUE KEY** (mapGameId, playerId, heroId) - 确保每个选手在每个地图局使用每个英雄只记录一次

## 支持一个队伍参加多个赛季的设计说明

### season\_teams表的设计原理

**UNIQUE KEY (seasonId, teamId)** 这个约束的含义是：

* ❌ **不允许**：同一个队伍在同一个赛季中出现多次

* ✅ **允许**：同一个队伍在不同赛季中出现多次

### 具体示例

#### 情况1：队伍A参加多个赛季

| id | seasonId | teamId |             |
| -- | -------- | ------ | ----------- |
| 1  | 1        | 1      | // 队伍A参加赛季1 |
| 2  | 2        | 1      | // 队伍A参加赛季2 |
| 3  | 3        | 1      | // 队伍A参加赛季3 |

这三个记录都是有效的，不会违反唯一键约束，因为 `seasonId` 不同。

#### 情况2：队伍A和队伍B在同一个赛季中比赛

| id | seasonId | teamId |             |
| -- | -------- | ------ | ----------- |
| 1  | 1        | 1      | // 队伍A参加赛季1 |
| 2  | 1        | 2      | // 队伍B参加赛季1 |

这两个记录也是有效的，不会违反唯一键约束，因为 `teamId` 不同。

### 数据一致性保障

* **唯一键约束**：确保数据不重复

* **外键关联**：确保数据的完整性和一致性

* **事务支持**：确保数据操作的原子性

### 核心功能支持

* **选手跨赛季换队**：通过 season\_team\_players 表实现

* **替补上场**：通过前端选择实现

* **换英雄**：通过 player\_stats 表的 heroId 字段实现

* **ban英雄**：在 map\_games 表中支持

* **1t2d2s限制**：通过前端验证实现
