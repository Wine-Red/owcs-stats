# 实现英雄禁用情况图表

## 需求分析
根据项目数据库结构，完成英雄禁用情况图表，使用横向条形图展示筛选赛段内所有地图局的英雄禁用数据统计分析。

## 技术方案

### 1. 后端API开发
- **修改 StatsController.js**：添加新的方法 `getHeroBanStats` 用于统计英雄禁用数据
- **修改 stats.js 路由**：添加新的路由 `/hero/ban` 指向新方法
- **数据处理逻辑**：
  - 从 MapGame 表中提取指定赛段的所有记录
  - 统计 team1BanHeroId 和 team2BanHeroId 字段
  - 按英雄ID分组，计算总禁用次数
  - 计算禁用率（禁用次数/总地图局数）
  - 按禁用次数降序排序，返回前10名

### 2. 前端API服务更新
- **修改 api.js**：添加新的方法 `getHeroBanStatsData` 用于调用后端API

### 3. 前端图表实现
- **修改 updateHeroBanChart 函数**：
  - 调用新的API获取英雄禁用数据
  - 使用 ECharts 实现横向条形图
  - 配置 X 轴为禁用次数，Y 轴为英雄名称
  - 添加悬停提示，显示英雄名称、禁用次数、禁用率
  - 添加图表下载功能
  - 确保英雄名称完整显示

### 4. 图表配置
- **图表类型**：横向条形图
- **数据排序**：按禁用次数降序
- **显示数量**：仅展示前10名
- **交互功能**：悬停提示、下载功能
- **视觉设计**：清晰易读，英雄名称完整显示，符合项目UI规范

## 实施步骤
1. 在后端添加英雄禁用统计API
2. 更新前端API服务
3. 修改前端图表实现
4. 测试图表功能
5. 优化用户体验

## 预期效果
- 页面加载后，根据筛选的赛季显示英雄禁用情况图表
- 图表使用横向条形图展示禁用次数前10的英雄
- 悬停时显示详细数据
- 提供图表下载功能
- 响应式设计，在不同设备上正常显示
