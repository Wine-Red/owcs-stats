# Implement Team Statistics Scatter Plot with Multi-Select Filter

## Backend Changes
### `backend/controllers/StatsController.js`
- Modify `getTeamStats` method:
  - After aggregating `PlayerStat`, iterate through each team's stats.
  - Query `MapGame` to calculate the total duration (`sum('duration')`) for each team in the specified season.
  - Add `totalDuration` to the response object for each team.

## Frontend Changes
### `src/views/visualize/Visualize.vue`
1.  **Enhance Team Filter**:
    - Change `teamFilter` to support multiple selections (array).
    - Update the `<el-select>` in the "Team Data Statistics" card header:
        - Add `multiple`, `collapse-tags`, `collapse-tags-tooltip` attributes.
        - Add `@change="updateTeamComparisonChart"` event listener.
        - Set default value to select all teams when data is loaded or season changes.
2.  **Update Chart Logic (`updateTeamComparisonChart`)**:
    - Update API call to use the local `teamFilter` value.
    - Calculate normalized statistics:
        - `Eliminations/10min` = `totalKills / (totalDuration / 600)`
        - `Damage/10min` = `totalDamage / (totalDuration / 600)`
    - Configure ECharts option for Scatter Plot:
        - X-Axis: Total Damage/10min.
        - Y-Axis: Total Eliminations/10min.
        - Series: Type `scatter`, with data points formatted as `[x, y]`.
        - Tooltip: Custom formatter to show Team Name and calculated stats.
        - Labels: Display team names.
3.  **Responsive Design**:
    - Ensure the filter and chart adapt well to different screen sizes.
