# 实现地图选取情况统计图表

## 需求分析
根据项目数据库结构，实现地图选取情况统计图表，使用100% 堆叠横向条形图展示各地图类型的选取率分布。

## 技术方案

### 1. 后端API开发
- **修改 StatsController.js**：添加新的方法 `getMapPickStats` 用于统计地图选取数据
- **修改 stats.js 路由**：添加新的路由 `/map/pick` 指向新方法
- **数据处理逻辑**：
  - 从 MapGame 表中提取指定赛段的所有记录
  - 按 mapId 统计选取次数
  - 关联 Map 表获取地图类型
  - 按地图类型分组，计算每种类型内各地图的选取率（选取次数/该类型总选取次数）
  - 过滤掉选取率为0的地图
  - 按地图类型和选取率排序

### 2. 前端API服务更新
- **修改 api.js**：添加新的方法 `getMapPickStatsData` 用于调用后端API

### 3. 前端图表实现
- **修改 updateMapPickChart 函数**：
  - 调用新的API获取地图选取数据
  - 使用 ECharts 实现100% 堆叠横向条形图
  - 配置 y 轴为地图类型（推进、护送、控制、混合、闪点）
  - 配置 x 轴为百分比（0-100%）
  - 为每种地图类型创建一个堆叠组
  - 确保不同地图类型的条形图之间无间距
  - 添加悬停提示，显示地图名称和选取率

### 4. 图表配置
- **图表类型**：100% 堆叠横向条形图
- **数据处理**：按地图类型分组，计算选取率
- **显示规则**：只显示选取率>0的地图
- **布局要求**：不同地图类型的条形图之间无间距
- **交互功能**：悬停提示，显示详细数据

## 预期效果
- 页面加载后，根据筛选的赛季显示地图选取情况图表
- 图表使用100% 堆叠横向条形图展示各地图类型的选取率分布
- y轴显示地图类型，x轴显示百分比（0-100%）
- 不同地图类型的条形图之间无间距，像一整块贴在一起
- 悬停时显示地图名称和选取率
- 只显示选取率>0的地图
