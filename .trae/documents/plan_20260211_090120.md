# 地图局 Excel 导入功能开发计划

## 1. 需求分析
根据您的要求，我们将实现一个地图局 Excel 导入功能，支持解析特定的 Excel 格式，并处理选手名称大小写不一致、时长单位转换以及队伍自动识别等问题。不需要关联“比赛 (Match)”。

## 2. 后端开发 (`backend/`)

### 2.1 路由与控制器
*   **路由**: 在 `routes/map-games.js` 中新增 `POST /import` 接口。
*   **控制器**: 在 `controllers/MapGameController.js` 中新增 `importMapData` 方法。

### 2.2 核心处理逻辑
*   **时长转换**: 接收前端传入的“X分X秒”字符串或秒数，转换为数据库所需的**分钟数** (Integer)，采用四舍五入策略（例如 6分32秒 -> 7分钟）。
*   **地图与获胜队伍解析**:
    *   从 Sheet 1 的 `mapName`（如“66号公路（WBG胜利）”）中分离出地图名（"66号公路"）和获胜者（"WBG"）。
    *   根据名称在数据库查找对应的 `Map` ID 和 `Team` ID。
*   **选手匹配 (忽略大小写与前缀)**:
    *   针对 Excel 中 "WBG-GUXUE" (全大写) 与数据库中 "Guxue" (混合大小写) 不一致的问题：
    *   先尝试直接忽略大小写匹配 (`LOWER(db_name) === LOWER(excel_name)`)。
    *   如果匹配失败，且 Excel 名称包含 `-`，则尝试匹配 `-` 后的部分（如 "GUXUE" -> "Guxue"）。
*   **队伍识别**:
    *   利用 Excel 中的 `teamId` (1或2) 对选手分组。
    *   通过已识别选手的所属队伍（查询 `SeasonTeamPlayer` 关联），推断出 Team 1 和 Team 2 对应的真实数据库 Team ID。
*   **事务写入**:
    *   创建 `MapGame` 记录 (`matchId` 设为 `NULL`)。
    *   批量创建 `PlayerStat` 记录。

## 3. 前端开发 (`src/views/data-manage/`)

### 3.1 新增组件 `MapDataImport.vue`
*   **依赖**: 使用 `xlsx` 库解析 Excel。
*   **界面**:
    *   赛季选择器 (Season Select)。
    *   文件上传区域 (File Upload)。
    *   **数据预览**:
        *   **对局信息**: 展示解析出的地图名、时长、获胜者等 Sheet 1 信息。
        *   **选手列表**: 展示解析出的选手名、英雄、数据，并标识匹配状态。
*   **解析逻辑**:
    *   读取 Sheet 1 获取对局元数据。
    *   读取 Sheet 2 获取选手战斗数据。
    *   构造符合后端要求的 JSON Payload。

## 4. 验证计划
*   **测试数据**: 使用包含“6分32秒”、“WBG-GUXUE”等特征的 Excel 文件。
*   **检查点**:
    *   `map_games` 表中 `duration` 是否正确转换为分钟。
    *   `player_stats` 表中 `playerId` 是否正确关联到数据库中的 "Guxue"。
    *   `teamId` 是否正确映射。

我们将按照此计划立即开始代码实现。
