# OWCS Stats 事件字典（口径 2）

由 `npm run docs:analytics` 从 `src/analytics/catalog.mjs` 生成。公共上下文包括页面、赛事、赛段、对阵、选手、战队、地图（按当前页面实际可用数据携带），以及相应追溯 ID。所有事件包含口径版本。

| 代码键 | Umami 事件名 | 专属字段 | 业务含义 |
| --- | --- | --- | --- |
| `page_load` | 访问-内容加载完成 | 指标、耗时毫秒、耗时区间、结果、结果数量 | 内容可用率、空数据率和加载耗时；不是页面浏览量 |
| `feature_view` | 功能-有效曝光 | 功能、结果、结果数量 | 功能进入视口并连续可见 1 秒，每次内容访问去重 |
| `tab_change` | 浏览-切换内容 | 内容分区、数据分类、展示模式、地图局ID、地图ID、功能 | 主动切换分区、地图和数据类别 |
| `season_change` | 浏览-切换赛事 | 入口 | 主动选择赛事的需求 |
| `open_match` | 导航-打开比赛 | 入口 | 从哪个入口进入哪场比赛 |
| `open_upcoming` | 导航-打开赛前分析 | 入口 | 赛前分析入口转化 |
| `open_team` | 导航-打开战队 | 入口 | 战队内容兴趣及入口 |
| `open_player` | 导航-打开选手 | 入口 | 选手内容兴趣及入口 |
| `back` | 导航-返回 | 入口 | 详情返回行为 |
| `filter_change` | 分析-调整筛选 | 功能、筛选项、筛选值、职责、筛选战队、筛选选手、地图ID、英雄ID、结果数量、已选人数 | 用户主动选择的分析范围 |
| `sort_change` | 分析-调整排序 | 功能、指标、排序方向、英雄ID | 最受关注的统计指标 |
| `expand` | 分析-展开明细 | 功能、展开状态、英雄ID、地图ID、选手ID、指标 | 深度分析使用情况 |
| `compare` | 分析-选择对比 | 功能、职责、筛选选手、对比选手、已选人数 | 对比选择；至少两名选手时才算完整对比 |
| `timeline_round` | 时间线-切换回合 | 回合、地图ID、地图局ID | 回合浏览需求 |
| `timeline_filter` | 时间线-筛选事件 | 筛选项、地图ID、地图局ID | 感兴趣的事件类型 |
| `timeline_event` | 时间线-查看事件 | 事件类型、地图ID、地图局ID、回合 | 主动打开时间线事件详情 |
| `replay_expand` | 录像-展开代码 | 入口、展开状态 | 录像代码发现情况 |
| `replay_copy` | 录像-复制代码结果 | 结果、地图ID | 剪贴板操作结果，不收集录像代码 |
| `vote_start` | 投票-提交支持 | 投票方式 | 投票尝试，区分首次与改投 |
| `vote_result` | 投票-提交结果 | 投票方式、结果、耗时毫秒、耗时区间、错误类别 | 投票成功率及错误类别 |
| `export_start` | 导出-开始生成 | 功能、导出类型、图表名称、透明背景 | 导出需求 |
| `export_result` | 导出-生成结果 | 功能、导出类型、图表名称、透明背景、结果、耗时毫秒、耗时区间、错误类别 | 图片生成预览成功率，不代表保存到设备 |
| `assistant_open` | 助手-打开 | 无 | 助手入口使用 |
| `assistant_context` | 助手-切换页面范围 | 结合页面 | 页面上下文使用 |
| `assistant_send` | 助手-发送问题 | 提问方式、结合页面、对话轮次 | 问题提交，不收集问题或对话内容 |
| `assistant_result` | 助手-回答结果 | 提问方式、结合页面、结果、耗时毫秒、耗时区间、首字毫秒、错误类别 | 回答完成率、停止率、首字和总耗时 |
| `api_error` | 质量-接口失败 | 资源、请求方式、HTTP状态、错误类别 | 公开页面接口故障，去除原始 URL 与错误文本 |
